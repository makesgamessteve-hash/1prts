# Screenshots

`01`–`12` are taken with `tests/game/scenarios/tour.lua` at 960×540 (OpenGL 3.3 core on Mesa
llvmpipe under Xvfb, retro preset 270 lines):

```sh
xvfb-run -a ./build/dev/bin/1stprts --size 960x540 --scenario tests/game/scenarios/tour.lua --out docs/screenshots
```

`13`–`17` show the user interface at 1280×720: the front-end menu, the video options, the
Credits screen, the touch controls (phone browsers) and the developer console with the
labeled observer camera (developer builds only).
